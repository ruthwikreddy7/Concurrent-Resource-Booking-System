# Concurrent-Resource-Booking-System

**A simple, reliable way to book seats when demand is high.**

Concurrent-Resource-Booking-System is a seat-booking project for places with limited seating, such as movie theaters, event halls, and workshops.

Imagine hundreds of people trying to book the same seat at the same time. SeatGuard is designed to make sure **only one person gets that seat**. Everyone else receives a clear message that it is no longer available.

## What Concurrent-Resource-Booking-System does

- Lets organizers create a seating area with rows and numbered seats.
- Shows people which seats are available and which are already booked.
- Allows someone to choose an available seat and receive a booking confirmation.
- Prevents two people from booking the same seat, even when they try at the same moment.
- Handles repeated booking requests without accidentally creating another booking.

## The goal

Make seat booking **simple, dependable, and trustworthy**, especially when many people are trying to book at once.

*This version focuses on booking one seat at a time. Payments, cancellations are outside its scope.*
